# AI Livelihood Navigator Pilot — ForeRunners Organization

**Status:** Prototype / demonstration only  
**Primary pilot focus:** Amarapura Township, Mandalay Region, with a wider intended audience of young people across Myanmar.  
**Languages:** Myanmar and English  
**Path:** `/livelihood-navigator/`

## What this prototype does
- Offers a short self-assessment about interests, skills, education, resources and preferred work style.
- Suggests up to three livelihood pathway categories.
- Generates a simple 30-day action plan.
- Drafts an outreach message that the user can edit.
- Supports text report export and browser print / Save as PDF.
- Performs assessment logic in the browser; no account or server submission is implemented.

## Important limitations
- This is a rule-based prototype, **not connected to a live AI model**.
- Suggested pathways are general categories, not verified vacancies, grants, training offers or referrals.
- There is no verified Myanmar opportunity directory, user account, application tracker, server-side data storage or admin dashboard yet.
- The prototype does not send email or contact any organization automatically.
- Users should independently verify eligibility, provider identity, deadlines, fees and safety before applying or sharing documents.

## Safeguarding and privacy
- Do not enter sensitive personal information such as full address, identity numbers, passwords or confidential case details.
- Answers are processed in the current browser session and are not sent to a server by this page.
- This prototype is not employment, financial, legal or psychosocial counselling advice.
- Before a public pilot, conduct youth safeguarding, accessibility, privacy and local-context reviews.

## Next development steps
1. Test the Burmese and English interface on mobile and desktop.
2. Review the pathway logic with youth and livelihood practitioners in Amarapura and other target communities.
3. Create a source-verified opportunity directory with source URL, provider, eligibility, location, deadline, verification date and status.
4. Add informed consent, data-minimisation and safeguarding procedures before collecting identifiable user data.
5. Only after review, consider a secure AI integration with human review and clear limitations.
