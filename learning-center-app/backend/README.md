# ForeRunners LMS Backend
The complete Supabase SQL migration and authenticated Edge Function source are available in the companion deliverable `forerunners-lms-backend.zip` (saved to ChatGPT Library).

The migration defines six courses, lessons, enrollments, progress, private quiz answer keys, server-scored attempts, assignments, staff review and certificates with Row Level Security.

**Deployment is not yet performed.** Create a Supabase project, run the reviewed migration, seed 10+ vetted questions per course, deploy the Edge Function, configure Auth and connect the frontend. Never put a service-role key in GitHub or browser code. Do not publicly issue certificates until the exam, grading, PDF and approval flows are tested.
