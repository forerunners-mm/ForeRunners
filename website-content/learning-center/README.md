# ForeRunners Learning Center — Draft Content Catalog
Six beginner courses in the organization's program areas. Each includes an introductory bilingual lesson concept and practical assignment. The expanded bilingual lessons, draft knowledge checks, rubrics, and six printable PDF handouts are packaged separately as `forerunners-learning-center.zip` in the ChatGPT deliverable.

## Access
Free public lesson reading; planned registration for assignment submission, final exams and certificates.

## Proposed completion requirements (NOT YET IMPLEMENTED)
80% lesson completion, 70% final exam, 70/100 assignment, and manual approval.

## Technical status
This is a content catalog, not an implemented LMS. Registration, secure submissions, grading, certificate issuance and PDF hosting still require backend/frontend integration. Do not issue certificates based on the single draft question per course. Do not commit participant identities, counseling case data, or private submissions into public GitHub.
